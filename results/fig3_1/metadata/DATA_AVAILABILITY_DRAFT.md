# Data availability draft

The Figure 3A-B hierarchy benchmark files supporting the deconvolution analyses
are provided in this release package. The package includes processed input
matrices, hierarchy definitions, result tables, per-tissue prediction outputs,
MetaSort gene-weight summaries, figure files, and scripts used to generate the
retained outputs.
